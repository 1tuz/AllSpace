# Релизы и установка

Релиз запускается пушем тега `v<X.Y.Z>`; `<X.Y.Z>` обязан совпадать с `version` в `apps/desktop/src-tauri/tauri.conf.json`, иначе job `verify` в `.github/workflows/desktop-release.yml` падает до сборки. Собираются две платформы: macOS Apple Silicon (`.dmg`) и Linux x86_64 (`.deb`, `.AppImage`). Job `publish` создаёт GitHub Release в `1tuz/AllSpace`, отказывается публиковать релиз без ассета хотя бы одной платформы и затем перечитывает ассеты через API. Установка — две curl-команды из `scripts/install.sh` и `scripts/uninstall.sh` (см. `docs/INSTALL.md`); вручную — ассеты со страницы релиза. Ограничения честные: сборки не подписаны и не нотаризованы, updater-фида нет, продукт — прототип. `release.yml` привязан к апстримному репозиторию и здесь пропускается; шипит именно `desktop-release.yml`. Упаковывается десктопный шелл `apps/desktop/src-tauri` поверх общего реестра, поэтому его границы описаны в заметке про краты.
